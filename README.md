# Brain Tumor Segmentation And Classification

Project notebook and explanation document for brain tumor segmentation and classification.

## Files

- `Brain Tumor Segmentation And Classification.ipynb`: data preparation, segmentation, classification, evaluation, and inference.
- `Model Explanation.pdf`: accompanying model explanation.

## Running the notebook

Open the notebook in Google Colab or a compatible Jupyter environment. The installation cell installs the required packages. The notebook uses Google Drive by default; adjust `DATA_ROOT` and `WORK_DIR` to point to your dataset and output folder.

The dataset and trained model weight files are not included.
